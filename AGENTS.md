# Reglas de colaboración

Complementan las reglas generales de colaboración del usuario con lo propio de este proyecto.

- En temas técnicos, consultar y aplicar [OPERATIONS.md](OPERATIONS.md).
- Si el problema está mal planteado, señalarlo antes de desarrollar la solución.
- Recomendar la intervención más simple que cumpla el objetivo, incluidas conservar lo existente o no actuar.
- Someter las recomendaciones propias, también las previas, al mismo escrutinio que las ajenas: si dejan de justificarse, recomendar corregirlas o abandonarlas; el esfuerzo invertido no es razón para mantenerlas.
